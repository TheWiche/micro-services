Teoría del Color en Diseño Web: Cómo Crear Paletas Armónicas

La regla del 60-30-10, contraste accesible WCAG y psicología cromática.

Extraer colores a partir de una fotografía de referencia es una de las técnicas más efectivas para inspirar la identidad visual de una marca o el sistema de diseño (UI) de una página web. La naturaleza y la fotografía profesional ya contienen armonías equilibradas de iluminación, contraste y temperatura.

La Regla de Oro del Diseño UI: 60 - 30 - 10

Para que una interfaz no resulte caótica ni sature la vista del usuario, los diseñadores aplican la regla proporcional de distribución:

60% Color Dominante

Suele ser el fondo neutro (blanco puro, gris pizarra claro o negro espacial) que proporciona aire y orden al contenido.

30% Color Secundario

Utilizado en tarjetas, barras de navegación y textos de encabezados para construir la estructura visual.

10% Color de Acento

El tono vibrante reservado exclusivamente para llamadas a la acción (botones CTA, enlaces, insignias y estados activos).

Formatos de Color: HEX vs RGB vs HSL

  • HEX (#RRGGBB): El formato hexadecimal más extendido en desarrollo web por su brevedad y facilidad para compartir.
  • RGB (Red, Green, Blue): Representa los valores de luz de 0 a 255. Ideal para manipular opacidades con rgba(r, g, b, 0.5).
  • HSL (Hue, Saturation, Lightness): El más intuitivo para diseñadores. Permite crear variantes claras u oscuras de un mismo tono modificando únicamente la luminosidad (L).
